# Ganpati Studio

Ganpati Studio lets a person create a respectful visual composition by choosing one murti foundation and then exploring compatible visual variations.

## Language

**Base Murti**:
The fixed Ganesha form, posture, proportions, and camera framing beneath one composition. A Base Murti does not change while its design is being customized.
_Avoid_: Pose, body, model

**Customization Slot**:
A named visual region that can accept one compatible Variant, such as Eyes, Ears, Trunk, Crown, Garland, Jewellery, Drape, or Scene.
_Avoid_: Category, layer, feature

**Variant**:
One selectable visual treatment for a Customization Slot.
_Avoid_: Asset, option, skin

**Design**:
One complete, compatible Base Murti and one selected Variant for every required Customization Slot.
_Avoid_: Character, avatar, generated image

**Asset Pack**:
The approved Base Murti and compatible Variants that share one coordinate system, lighting direction, and visual style.
_Avoid_: Theme, filter
